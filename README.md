# LabLock

Εργαλείο κλειδώματος για εργαστήρια πληροφορικής σχολείων (Windows 10 / 11), χωρίς Deep Freeze.
Ένα μόνο `LabLock.exe` που τρέχει από USB, με τσεκ σε ό,τι θέλεις να εφαρμοστεί, και επαναφορά όλων με ένα κουμπί.

*A lockdown tool for school computer labs (Windows 10/11): one portable exe, tick what to apply, restore everything with one button. Greek and English interface.*

**Λήψη:** [τελευταία έκδοση (Releases)](https://github.com/mgiakalaras/LabLock/releases/latest) → `LabLock.exe`

## Τι κάνει

- **Λογαριασμοί:** χωριστός διαχειριστής, ο κοινός λογαριασμός μαθητή γίνεται τυπικός χρήστης (βρίσκεται από το SID, όποιο κι αν είναι το όνομα του φακέλου του), κλείδωμα μετά από λάθος κωδικούς.
- **Μαθητής:** κλείδωμα Ρυθμίσεων και Πίνακα Ελέγχου, ταπετσαρίας, χρωμάτων, εικόνας προφίλ και οθόνης κλειδώματος (με το λογότυπο του σχολείου), μη εκτέλεση προγραμμάτων από Λήψεις / Επιφάνεια εργασίας / USB, καθάρισμα στη σύνδεση.
- **Browsers και ιστοσελίδες:** ρυθμίσεις για κοινόχρηστο λογαριασμό, τοπική λίστα αποκλεισμού (π.χ. παιχνίδια web) που δουλεύει και όταν πέσει το Pi-hole, κλείδωμα DNS στο firewall.
- **Υπολογιστής:** σταθερή IP και DNS, μετονομασία, Wake-on-LAN (κάρτα δικτύου, Γρήγορη εκκίνηση), αυτόματο κλείσιμο το βράδυ, σημείο επαναφοράς.
- **Αρχείο PC:** όνομα, IP, MAC και υλικό κάθε υπολογιστή, εξαγωγή για Veyon και NetHawk, άνοιγμα όλων με Wake-on-LAN.
- **Πίνακες:** καθημερινό κλείσιμο για τα Windows 11 των διαδραστικών πινάκων.
- **Εκκίνηση:** ένας μικρός καθαριστής για τα προγράμματα που ανοίγουν με τα Windows.
- **Έλεγχος υγείας:** 17 έλεγχοι μόνο ανάγνωσης.
- **Επαναφορά PC:** κάθε PC κρατά δικό του αρχείο με ό,τι άλλαξε και πώς ήταν πριν, και το ξαναφέρνει όπως ήταν.
- **Πολλά PC μαζί:** `LabLock.exe /apply`, `/undo`, `/restore`, `/wake` και `Push-LabLock.ps1` από το PC του καθηγητή.
- **School Network Manager:** αν δοθεί η διεύθυνσή του, κάθε PC στέλνει εκεί τι κλείδωμα έχει.

## Χτίσιμο

Χωρίς Visual Studio: διπλό κλικ στο `build.cmd` (χρησιμοποιεί τον C# compiler του .NET Framework 4 που έχουν τα Windows).
Ή άνοιγμα του `LabLock.sln` στο Visual Studio. Σε κάθε ανέβασμα το GitHub το χτίζει μόνο του (καρτέλα **Actions**· το workflow είναι στο `ci/build.yml`).
